# Spec Delta

## Purpose

首版不解析语音、图片、文件与视频，但这些消息必须得到确定性、可解释的降级响应，并为后续接入真实多模态能力保留统一扩展点，绝不因未知类型而崩溃。

## ADDED Requirements

### Requirement: 非文本消息必须得到确定性降级响应

系统 SHALL 将图片、语音、文件、视频识别为暂不支持的多模态消息：对白名单内发送者回复一条固定降级话术且 MUST NOT 调用 LLM；对白名单外发送者保持静默丢弃。

#### Scenario: 白名单内发送图片得到降级话术

- **GIVEN** 白名单内发送者发来一张图片
- **WHEN** 系统处理该消息
- **THEN** 用户收到「暂不支持图片」之类的固定话术，LLM 未被调用，进程继续正常运行

#### Scenario: 非白名单发送语音保持静默

- **GIVEN** 非白名单发送者发来一条语音
- **WHEN** 系统处理该消息
- **THEN** 不发送任何内容，仅记录一条丢弃日志

#### Scenario: 未知消息类型不导致崩溃

- **GIVEN** 消息包含首版未定义的内容类型
- **WHEN** 系统解析该消息
- **THEN** 归类为未知类型并走默认降级路径，主循环不中断

### Requirement: 混合消息只使用其中文本部分

系统 SHALL 对同时包含文本与媒体的消息，仅使用文本部分走正常回复流程，并在回复末尾追加「附件暂不支持」的提示；无文本时按纯媒体消息降级。

#### Scenario: 图文混发时基于文本回复

- **GIVEN** 白名单内发送者发来「帮我看下这个」并附带一张图片
- **WHEN** 系统处理该消息
- **THEN** 回复基于文本内容生成，并追加附件未处理的提示

#### Scenario: 仅媒体的混合消息走纯降级

- **GIVEN** 消息包含图片与空白文本
- **WHEN** 系统处理该消息
- **THEN** 仅发送降级话术，不调用 LLM

### Requirement: 统一的多模态抽象与处理器注册

系统 SHALL 将入站消息统一归类为 text / image / voice / file / video / unknown，并提供按类型注册处理器的扩展点；未注册处理器或处理器抛出异常时 MUST 回落到默认降级处理。

#### Scenario: 未注册的处理器回落到默认降级

- **GIVEN** 某消息类型没有注册任何处理器
- **WHEN** 系统分发该消息
- **THEN** 使用默认降级处理器，不抛出未捕获异常

#### Scenario: 处理器异常被隔离

- **GIVEN** 已注册的处理器在处理过程中抛出异常
- **WHEN** 系统捕获该异常
- **THEN** 该条消息改用默认降级回复，后续消息继续正常处理

### Requirement: 首版不下载或解密媒体资源

系统 SHALL 不发起媒体下载、CDN 请求或解密操作；仅记录媒体类型的元信息，MUST NOT 将媒体内容写入本地或日志。

#### Scenario: 收到文件时不发起下载

- **GIVEN** 白名单内发送者发来一个文件
- **WHEN** 系统处理该消息
- **THEN** 不产生任何媒体下载请求，仅发送降级话术并记录媒体类型

#### Scenario: 媒体内容不落盘

- **GIVEN** 系统处理过多条图片与语音消息
- **WHEN** 检查本地数据目录与日志
- **THEN** 不存在媒体文件或媒体二进制内容，只有类型与大小等元信息

### Requirement: 降级话术可配置且具备默认值

系统 SHALL 允许通过配置自定义降级话术；未配置时 MUST 使用内置默认中文话术，且话术长度不超过单条消息上限。

#### Scenario: 未配置时使用默认话术

- **GIVEN** 配置中没有设置降级话术
- **WHEN** 收到一条图片消息
- **THEN** 发送内置默认话术

#### Scenario: 自定义话术生效

- **GIVEN** 配置中为图片类型设置了自定义话术
- **WHEN** 收到一条图片消息
- **THEN** 发送该自定义话术而非默认文案
