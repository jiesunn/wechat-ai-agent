# 演示视频录制脚本

目标总时长 **3–5 分钟**（本脚本约 4 分 10 秒）。按顺序录一遍即可，不需要剪辑。

## 录制前准备

- 屏幕录制需保留 **macOS 菜单栏**；终端窗口不要全屏，保留 **标题栏**（Terminal.app 可在「显示 → 显示标题栏」打开，标题写 `wechat-agent`）。这两处用于证明运行环境是 macOS。
- 终端字号调到 16 以上，让日志关键字可读；深色背景、浅色文字。
- 手机投屏到电脑（QuickTime 或 iPhone 镜像），提前把联系人昵称、头像、微信号打码。
- `.env` 按 `docs/acceptance.md` 的「环境准备」填好；`DATA_DIR` 建议用独立的 `data-demo`，避免演示数据混入正式记忆。
- 场景 1–4 使用 `DRY_RUN=false`；场景 5 临时改为 `DRY_RUN=true`。
- 关闭无关通知与聊天列表预览，避免弹出真实联系人信息。

## 场景与节奏

### 场景 1：启动与文本回复（0:00–1:00，60 秒）

**操作**

1. 终端执行 `python -m wechat_agent`。
2. 出现二维码时先打码，再扫码；扫码完成后恢复画面。
3. 小号发送：「你好，帮我写一句周末计划」。

**旁白要点**

- 单进程 asyncio，扫码后进入长轮询；白名单、过滤链、记忆、LLM、降级都在一条管线里。
- 当前是真实发送模式，机器人会直接把回复发回微信。

**预期画面**

- 终端依次出现：`应用已启动` → `正在扫码登录` → `登录成功` → `开始轮询`；收到消息后出现 `LLM 调用成功`。
- 手机端收到一句中文回复，内容符合默认人设。

**打码**：二维码、手机昵称、头像、微信号。

### 场景 2：白名单外静默（1:00–1:35，35 秒）

**操作**：用另一个不在 `ALLOW_FROM` 里的账号给机器人发一条文本。

**旁白要点**

- 白名单是精确匹配、fail-closed；非白名单在过滤链第一步就被丢弃，不消耗 LLM 配额。
- 日志只记录联系人哈希，不记录原始 wxid 和消息正文。

**预期画面**

- 终端：`消息被过滤 ... stage=whitelist reason=not_in_whitelist`。
- 手机端：没有任何回复。

**打码**：这个账号的昵称、头像、wxid。

### 场景 3：图片降级（1:35–2:20，45 秒）

**操作**：小号发送一张图片。

**旁白要点**

- 多模态在 LLM 之前分流；媒体不下载、不落盘，也不消耗模型调用。
- 未注册的媒体类型和处理器异常都会回落到默认降级话术。

**预期画面**

- 终端：`媒体类型未注册处理器，回落默认降级`、`媒体消息使用默认降级话术`；该条消息没有 `LLM 调用成功`。
- 手机端收到默认降级话术（或 `.env` 中配置的 `UNSUPPORTED_MEDIA_REPLY`）。

**打码**：图片内容如涉及隐私需打码，手机昵称与头像始终打码。

### 场景 4：记忆连续性（2:20–3:20，60 秒）

**操作**

1. 小号发送：「我叫小林，喜欢喝美式」。
2. 等回复后发送：「你还记得我叫什么、喜欢喝什么吗？」

**旁白要点**

- 短期窗口保存最近 20 条；只有发送成功才写 assistant 记录，避免把未送达的回复当成事实。
- 长期摘要按「新增 10 条或空闲 10 分钟」触发，失败不阻塞回复。

**预期画面**

- 终端：两条消息各出现一次 `LLM 调用成功`，无异常。
- 手机端：第二轮回复能提到「小林」和「美式」。

**打码**：不要打开 `data/memory/` 下的 JSON（含对话正文）；手机昵称与头像打码。

### 场景 5：DRY_RUN 对比（3:20–4:10，50 秒）

**操作**

1. 在终端按 `Ctrl-C`，展示优雅停机：`收到停机信号` → `进程已停止`。
2. 把 `.env` 的 `DRY_RUN` 改为 `true`，重新执行 `python -m wechat_agent`（已有凭证，无需扫码）。
3. 小号再发一条文本。

**旁白要点**

- 真实发送前先用 DRY_RUN 预演拟发送内容；DRY_RUN 只打印，不调用发送接口。
- 停机信号会停止轮询、等待在途消息，游标与记忆都已落盘。

**预期画面**

- 终端：`应用已启动 dry_run=True` → `登录成功` → `开始轮询` → `[DRY_RUN] 目标=wxid_xxx 内容=...`。
- 手机端：没有新回复。

**打码**：`[DRY_RUN] 目标=` 行含 wxid，需要遮挡目标部分；不要展示 `.env` 内容。

## 收尾与文件

- 总时长控制在 3–5 分钟；五段之间可以用一句话过渡，不要留长空白。
- 文件命名：`wechat-agent-demo-YYYYMMDD.mp4`。
- 存放位置：`~/Movies/wechat-agent-demo/`，**不要提交到仓库**（视频体积大且含个人信息）。
- 录制后逐项检查：
  - [ ] macOS 菜单栏或终端标题栏全程可见
  - [ ] 完整二维码未出现在任何一帧
  - [ ] 联系人昵称、头像、微信号、手机号已打码
  - [ ] `.env`、`data/credentials.json`、`data/memory/*.json`、`data/logs/app.log` 未被展示
  - [ ] 五个场景齐全，总时长 3–5 分钟
